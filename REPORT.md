# Отчёт по проекту «OA — сайт с логином и регистрацией»

## Технологии

Сайт работает полностью на HTML, CSS и JavaScript. Сервер и PHP не требуются.

## Авторизация

Регистрация и вход реализованы в `js/validate.js`.
Пользователи сохраняются в `localStorage` под ключом `oa_users`, а текущая
сессия хранится под ключом `oa_current_user`.

Флажок «Запомнить email на 30 дней» использует настоящую cookie
`oa_remember_email` через `document.cookie`. Она сохраняет только email и не
сохраняет пароль.

Кабинет находится в `dashboard.html`. Скрипт `js/dashboard.js` проверяет сессию,
показывает имя пользователя и обрабатывает кнопку выхода.

Это демонстрационная авторизация. Данные находятся только в браузере и не
защищены сервером, поэтому такой способ не подходит для настоящего публичного
сайта.

## Валидация

Разрешены адреса `gmail.com`, `mail.ru`, `yahoo.com`, `yahoo.co.uk`,
`outlook.com`, `outlook.co.uk`, `hotmail.com` и `live.com`. При регистрации
пароль должен содержать минимум 8 символов, заглавную и строчную латинские
буквы и цифру. Также проверяются имя, совпадение паролей и уникальность email
без учёта регистра.

## Структура файлов

```text
site/
├── index.html       — вход и регистрация
├── dashboard.html   — пустой экран с логотипом и аккаунтом
├── REPORT.md        — этот отчёт
├── css/style.css    — стили сайта
└── js/
    ├── validate.js  — табы, валидация, регистрация и вход
    └── dashboard.js — проверка сессии и выход
```

## Запуск

Можно открыть `index.html` двойным кликом. Если браузер ограничивает
`localStorage` для локальных файлов, запустите статический сервер из папки
`site`, например:

```text
python -m http.server 8000
```

После этого откройте `http://localhost:8000/`.

Формы имеют метод `POST`, но JavaScript перехватывает отправку и обрабатывает
данные локально, поэтому реального HTTP-запроса `POST` сейчас нет. `GET` также
не используется, так как для работы сайта сервер не нужен.
